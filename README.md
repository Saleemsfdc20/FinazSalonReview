# FinazSalonReview

QR-based smart customer feedback & Google review generator machine designed for **Finaaz The Beauty Salon & Aesthetics** (Mahim West, Mumbai).

## Features
- **Fair Review Routing**: Identical options for all star ratings (1 to 5 stars) — customers can choose between public Google Reviews and private feedback to the owner.
- **Millions of Unique Combinations**: Multi-template combinatorial review engine generating authentic, non-repetitive salon reviews tailored to nails, hydrafacials, hair spas, cleanliness, and ladies-only privacy.
- **Zero Duplication Guarantee**: Server-backed hash tracking ensures once a customer copies a review, it is never shown to another customer.
- **Multilingual Support**: Real-time language switching between English, Hindi (हिंदी), and Marathi (मराठी).
- **Private Feedback System**: Direct WhatsApp messaging + optional Google Apps Script Google Sheets logging.
- **Local Network Support**: Built-in Node.js server with cross-device IP broadcasting for smartphone QR code testing.

## How to Run on Windows
1. Double-click `run.bat` to launch the local server and open the web page.
2. Or run via terminal:
   ```bash
   node server.js
   ```
3. Open `http://localhost:3000` on your PC, or open the displayed local IP address on your phone over Wi-Fi.
